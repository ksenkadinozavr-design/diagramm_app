# Планировщик постов по Крыму

Приложение для автоматизации контент-плана: на каждую дату создаётся пост с:

- датой;
- местом в Крыму;
- описанием;
- тремя найденными фотографиями.

## Быстрый запуск

Откройте `index.html` в браузере.

## Что умеет

- Генерация постов на диапазон дат (`28.05.2026` → `05.09.2026` по умолчанию).
- Кнопка **«Сделать 100 постов»** — автоматически формирует 100 дат от стартовой.
- Поиск 3 изображений по каждому месту через Wikimedia Commons API.
- Экспорт плана в `JSON` и `CSV`.

## Примечание

Если Wikimedia вернула меньше 3 фото, используется резерв из `picsum.photos`.
